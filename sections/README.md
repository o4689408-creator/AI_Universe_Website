# /sections

Reserved for the next phase. This is where composed, page-specific
sections live — e.g. `HeroSection`, `FeaturedTopicSection`,
`LatestContentSection`, `YouTubeSection`, `NewsletterSection` for the
homepage, and their equivalents for the article page.

Each section is composed from the primitives in `/components`
(`Container`, `Section`, `ContentCard`, `Button`, etc.) rather than
introducing new one-off markup — see Design System spec §4 (Component
Architecture) for the full rationale.
